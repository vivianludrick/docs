Files ending in `.mdx` can import any Svelte component from `src/components`
using the `@components/*` alias, then use it like HTML.

```mdx
import Callout from "@components/Callout.svelte";

<Callout client:load type="tip">
  Hello
</Callout>
```

## Callouts

<Callout client:load type="tip" title="Tip">
  Use `type="note" | "tip" | "warning" | "danger"`.
</Callout>

<Callout client:load type="warning">
  Drafts are visible in `pnpm dev` but hidden from the deployed site.
</Callout>

## Inline video block

A document is a sequence of blocks you read or watch. Besides the `videos:` list in
frontmatter (shown at the top), you can place a video anywhere in an `.mdx` file:

```mdx
import Video from "@components/Video.svelte";

<Video client:visible id="AdNJ3fydeao" title="Rethinking reactivity" />
```
